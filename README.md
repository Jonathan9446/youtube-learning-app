# YouTube Learning Assistant 🎥➡️🇮🇳

A free web app that converts YouTube videos into Hindi learning content with translations and phonetic pronunciations.

## 🌟 Features

- 🎬 **YouTube Video Processing** - Direct video URL processing
- 🔊 **AI Transcription** - Whisper-based English transcription
- 🇮🇳 **Hindi Translation** - Accurate sentence-wise translation  
- 🔤 **Hindi Pronunciation** - Phonetic Devanagari script
- ⏱️ **Timestamps** - Click to jump to specific video moments
- 📱 **Progressive Loading** - Handles long videos (100+ minutes)
- 🆓 **100% Free** - Uses free AI services and hosting
